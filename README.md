# ChaosNexus Website

VitePress documentation site for [chaosnexus.ai](https://chaosnexus.ai).

> **Status:** early public alpha launch (pre-1.0).

- **Contribute:** [github.com/TunedChaos/chaosnexus-website](https://github.com/TunedChaos/chaosnexus-website)
- **Support:** [Tuned Chaos supporters](https://tunedchaos.com/supporters/) or [GitHub Sponsors](https://github.com/sponsors/TunedChaos)
GitHub is the primary public host. Please open issues and pull requests on **GitHub**.

## Develop

From a checkout that contains sibling ChaosNexus components (or this tree after subtree publish):

```bash
pnpm install
pnpm website:dev
```
