# Support the Project

ChaosNexus is AGPL open source, built and maintained by a **solo developer** (Tuned Chaos). Sponsoring does not buy an SLA, guaranteed response times, or dedicated chat support — it buys more hours for sandboxing, Forge, and local model work.

## GitHub Sponsors

Primary support channel:

- [github.com/sponsors/TunedChaos](https://github.com/sponsors/TunedChaos)

Public repos list Sponsors via `.github/FUNDING.yml`, and each README links here.

### What sponsorship is (and is not)

| Is | Is not |
|----|--------|
| Funding continued OSS development | A support contract |
| Optional thanks / credits where noted | Priority engineering on demand |
| Appreciated at any amount | 24/7 chat or company Slack |

Bug reports stay on **[TunedChaos/chaosnexus-suite Issues](https://github.com/TunedChaos/chaosnexus-suite/issues)** for everyone — sponsors do not skip the queue by default.
